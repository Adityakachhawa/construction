# ConstructCalc Design System

A rugged, utility-first design system built for the construction trade. High-contrast typography, safety-amber accents, and a layered depth model that prioritizes readability in high-glare environments (e.g., on-site mobile use).

## Colors

- **Primary**: `#c2410c` (Construction Amber) — Used for primary CTAs and brand accents. Provides AA contrast against white.
- **Ink**: `#0a0a0a` — Deep neutral used for dark-themed sections.
- **Canvas**: `#ffffff` — Default card and component surface.
- **Canvas Soft**: `#f4f5f7` — Page background.
- **Text Primary**: `#0f1117` — High-contrast text.
- **Text Secondary**: `#4b5563` — De-emphasized text.
- **Border Default**: `#e2e4e8` — Standard UI borders.

## Typography

- **Sans-serif**: `'Inter Variable', 'Inter', system-ui, sans-serif`
- **Monospace**: `'JetBrains Mono', 'Fira Code', monospace`

| Level | Size | Weight | Use |
|-------|------|--------|-----|
| Display XL | 64px | 900 | Hero headlines |
| Display LG | 40px | 800 | Section titles |
| Body MD | 16px | 400 | Paragraphs |
| Caption Mono | 13px | 600 | Technical labels |

## Design Principles

1. **Sentence-case headlines only.** No Title Case or All-Caps for narrative text.
2. **High-contrast primary actions.** Amber on white or white on amber.
3. **Utility first.** Results should be prominent, accurate, and easy to copy.
4. **Responsive diagrams.** Visual aids must scale and remain legible on small screens.
5. **Layered depth.** Surfaces use a 3-layer model (page -> card -> raised) with subtle stacked shadows.
